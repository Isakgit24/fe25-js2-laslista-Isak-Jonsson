# fe25-js2-laslista-Isak-Jonsson

What the project does

It let you add video games to a list and favorite them or delete them. but also sort and filter the games you have added, by alphabetical order and first added to last and vis versa.

Why the project is useful

to make a list of video games you like and favorite game you like the most. 

How users can get started with the project?
You can get started by writing the title and the studio of the game you want to add. then you can favorite a game by pressing the hollow heart icon if they like, they can also unfavorite the game by pressing the full heart icon , users can also delete games they have added if they want by pressing the trashcan icon.
